# Vibe Coding Gallery PRD

## 1. 产品概述

Vibe Coding Gallery 是一个成熟的 vibe coding 作品发现与交流平台。用户可以浏览已有项目、按分类筛选、搜索项目、提交自己的作品链接、说明使用方式和创作目的，并围绕项目进行评论、收藏、点赞和举报。

产品不是一个简单链接导航站，而是一个围绕“AI 辅助创作网站/应用”的内容社区。

## 2. 产品目标

- 帮助浏览者快速找到有启发的 vibe coding 项目。
- 帮助创作者展示自己的作品、说明创作目的和使用方式。
- 通过分类、标签、搜索、榜单和精选机制提高内容发现效率。
- 通过评论、收藏、点赞和举报形成社区互动与治理。
- 通过审核后台保证内容质量和平台可信度。

## 3. 用户角色

### 游客

- 浏览公开项目。
- 使用搜索和分类筛选。
- 查看项目详情、评论和作者主页。

### 注册用户

- 提交项目。
- 评论、点赞、收藏项目。
- 编辑自己提交的项目。
- 举报项目或评论。

### 创作者

- 管理个人主页。
- 展示自己的项目集合。
- 查看项目表现数据。

### 管理员/运营

- 审核投稿。
- 设置精选项目。
- 管理分类、标签和举报。
- 处理低质内容、垃圾链接和违规评论。

## 4. 核心用户路径

### 浏览路径

1. 用户进入首页。
2. 通过搜索、分类、榜单或精选入口进入项目列表。
3. 点击项目卡片进入详情页。
4. 查看项目目的、使用方式、截图、链接和评论。
5. 收藏、点赞或评论。

### 投稿路径

1. 用户登录。
2. 进入提交项目页。
3. 填写项目链接、标题、简介、用途、使用方式、分类和标签。
4. 上传截图或填写预览图链接。
5. 提交后进入待审核状态。
6. 审核通过后公开展示。

### 运营路径

1. 管理员进入后台。
2. 查看待审核项目。
3. 检查链接、内容质量、分类和截图。
4. 通过、驳回或要求修改。
5. 将优质项目加入精选或专题。

## 7. 内容质量规则

- 项目链接必须可访问。
- 标题不能泛化，例如“我的网站”。
- 简介必须说明项目用途。
- 使用方式必须让用户知道如何体验。
- 分类和标签必须准确。
- 不允许恶意链接、钓鱼、成人内容、侵权内容和纯广告。

## 8. 排序与推荐

热度分建议：

```text
hot_score =
  views * 0.1 +
  likes * 2 +
  bookmarks * 3 +
  comments * 4 +
  editor_boost -
  age_decay
```

成熟版要避免只按点赞排序，否则早期项目会长期霸榜。

## 9. 成功指标

- 投稿转化率
- 审核通过率
- 首页项目点击率
- 项目详情页外链点击率
- 收藏率
- 评论率
- 搜索无结果率
- 七日回访率
- 每周新增高质量项目数

## 10. 非功能要求

- 首页首屏加载应尽量低于 2 秒。
- 项目详情页必须可被搜索引擎索引。
- 图片需要懒加载和尺寸优化。
- 登录、提交、评论需要限流。
- 管理后台必须有权限控制。
- 所有用户输入必须校验和转义。
